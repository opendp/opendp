Contact
=======

.. All of these lists should be in sync:
.. - README.md
.. - docs/source/contributing/contact.rst
.. - docs/source/_templates/questions-feedback.html

* Report a bug or request a feature on `Github <https://github.com/opendp/opendp/issues>`_.
* Issues should be filed for privacy-guarantee bugs so they can be resolved in the open. If you are concerned about describing the bug publicly, email `security@opendp.org <mailto:security@opendp.org>`_.
* Email `contact@opendp.org <mailto:contact@opendp.org>`_ to ask to join our Slack, and for general inquiries.
