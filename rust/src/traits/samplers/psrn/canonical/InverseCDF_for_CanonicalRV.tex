Proves soundness of the implementation of \rustdoc{traits/samplers/psrn/trait}{InverseCDF}
for \rustdoc{traits/samplers/psrn/canonical/struct}{CanonicalRV}.

The implementation computes the inverse CDF of the canonical noise random variable.

\subsection*{Precondition}
\subsubsection*{Compiler-verified}
\begin{itemize}
    \item Argument \texttt{self} of type \rustdoc{traits/samplers/psrn/canonical/struct}{CanonicalRV}.
    \item Argument \texttt{uniform} of type \texttt{RBig}.
    \item Argument \texttt{refinements} of type \texttt{usize}.
    \item Generic \texttt{R} implements \rustdoc{traits/samplers/psrn/trait}{ODPRound} which denotes the rounding mode, either up or down.
\end{itemize}

\subsubsection*{Caller-verified}
The argument \texttt{uniform} is in $[0,1]$.
The scale is nonnegative, and \texttt{self.tradeoff}, whenever it succeeds,
evaluates a fixed symmetric nontrivial tradeoff function $f$ exactly,
with fixed point \texttt{self.fixed\_point} in $[0,1/2)$.

\subsection*{Postcondition}

\begin{theorem}
Let $F_f$ be the canonical CDF for $f$ and let $s$ and $t$ be the
scale and shift, respectively.
For $u=\texttt{uniform}\in(0,1)$, the function returns
\[
    t+sF_f^{-1}(u)
\]
exactly, or propagates an error from evaluating $f$.
At $u\in\{0,1\}$ it returns \texttt{None} (a bound is unavailable).
Whenever a bound is available, its error is zero, independently of
the requested rounding direction and number of refinements.
\end{theorem}

\begin{proof}
The caller-verified conditions establish the preconditions of
\texttt{quantile\_cnd}. By its postcondition, on line~\ref{f_inv}
an available result is the deterministic quantile $F_f^{-1}(u)$,
not a random sample. Unavailable bounds and errors are propagated.

For $s>0$, the quantile of $t+sN$ for $N$ with CDF $F_f$ is
$t+sF_f^{-1}(u)$. For $s=0$, this expression is the quantile of the
point mass at $t$ for every interior $u$.
All arithmetic is exact, so the returned value satisfies both rounding
directions and its error cannot increase with refinements.
Sampling occurs when the quantile is evaluated at a uniform random
variable, not in this inverse-CDF implementation.
\end{proof}
