\subsection*{Postcondition}
\begin{theorem}
For any rational $p\in[0,1]$, \texttt{sample\_bernoulli\_rational}
either fails due to insufficient system entropy or returns
$\top$ with probability exactly $p$ and $\bot$ otherwise.
\end{theorem}

\begin{proof}
Write $p=n/d$ with nonnegative integer numerator $n$ and
positive integer denominator $d$, where $n\le d$.
The uniform integer sampler draws $U$ uniformly from
$\{0,\ldots,d-1\}$ and the function returns $U<n$.
Exactly $n$ of these $d$ outcomes satisfy the inequality,
so the success probability is $n/d=p$.
\end{proof}
