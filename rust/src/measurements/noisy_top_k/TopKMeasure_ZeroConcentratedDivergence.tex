\subsection*{Postcondition}
\begin{theorem}
    The implementation is consistent with all associated items in the \rustdoc{measurements/noisy\_top\_k/trait}{TopKMeasure} trait.
    \begin{enumerate}
        \item Method \texttt{privacy\_map}:
        For any $x, x'$ where $d_\mathrm{in} \ge d_\mathrm{Range}(x, x')$,
        return $d_\mathrm{out} \ge D_\mathrm{self}(f(x), f(x'))$,
        where $f(x) = \mathrm{noisy\_top\_k}(x=x, k=k, \mathrm{scale}=\mathrm{scale}, \mathrm{replacement}=\mathrm{self.replacement()})$.
    \end{enumerate}
\end{theorem}

\begin{proof}[Proof of postcondition: \texttt{privacy\_map}]

    At zero sensitivity the output distributions agree; at positive sensitivity and zero scale an infinite bound is valid.
    Otherwise \cite{Dong2019OptimalDP} Proposition~2 shows that the exponential mechanism satisfies Bounded Range.
    \cite{cesar2020bounding} Lemma 3.2 bounds its zCDP parameter by the square of the range parameter divided by eight.
    Adaptive composition multiplies this bound by $k$, with upward rounding.
\end{proof}
