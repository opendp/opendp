\subsection*{Postcondition}
\begin{theorem}
    \label{postcondition}

    \begin{itemize}
        \item If \texttt{scale} is zero, returns the indices of the $\min(k, |x|)$ greatest scores by deterministic peeling.
        \item Otherwise, if replacement is set, returns a sample from $\mathcal{M}_{EM}$ (as defined in MS2020 Definition 4),
            otherwise returns a sample from $\mathcal{M}_{PF}$ (as defined in MS2020 Lemma 1),
            $\min(k, |x|)$ times by peeling,
            where $\texttt{scale} = \frac{2 \cdot \Delta}{\epsilon}$.
        \item Errors are data-independent, except for exhaustion of entropy.
    \end{itemize}
\end{theorem}

\begin{proof}
    The pseudocode applies \rustdoc{measurements/noisy_top_k/fn}{permute\_and\_flip} on line~\ref{permute-and-flip}
    exactly $\min(k, |x|)$ times, where $|x|$ is the initial number of scores.
    The remaining input is nonempty at each call and the scale precondition is inherited,
    and the function each time removes the selected score on line~\ref{remove-score}.

    Since the index in subsequent selections may be offset by an earlier removal,
    a data-independent postprocessing of the index is performed on line~\ref{postprocess}.

    The only source of error is due to entropy exhaustion.
\end{proof}
