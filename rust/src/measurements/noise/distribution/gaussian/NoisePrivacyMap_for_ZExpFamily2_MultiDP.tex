\subsection*{Postcondition}
\begin{theorem}
Given a distribution \texttt{self}, the implementation returns an error if
\texttt{self} is invalid. Otherwise it returns a privacy map for the mechanism
\texttt{function(x) = x + Z}, where the coordinates of $Z$ are independent
discrete Gaussian samples represented by \texttt{self}, under
\texttt{MultiDP}.
\end{theorem}

\begin{proof}
Line \ref{line:zcdp-map} delegates to the exact-zCDP privacy map proved in
\texttt{NoisePrivacyMap\_for\_ZExpFamily2.tex}. That map validates the scale and
sensitivity and returns the conservative value of $\rho$ established by the
discrete-Gaussian zCDP theorem.

Line \ref{line:curve} wraps this exact zCDP distance in a
\texttt{PrivacyGuarantee} with source delta zero. Consequently the advertised
\texttt{MultiDP} capability contains exactly the zCDP representation already
proved for this mechanism. No Gaussian-DP or RDP representation is inferred
from the distribution name; those representations, if useful, can be derived
later by consumers using their respective theorems. The privacy guarantee is
therefore valid under \texttt{MultiDP}, and increasing the distance to any
\texttt{d\_out} accepted by the measure ordering preserves the guarantee.
\end{proof}
