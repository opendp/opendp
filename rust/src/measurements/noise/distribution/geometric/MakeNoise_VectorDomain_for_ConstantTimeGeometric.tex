\contrib
Proves soundness of the implementation of \rustdoc{measurements/noise/trait}{MakeNoise}
for \texttt{ConstantTimeGeometric}.

This implementation adds bounded geometric noise to each coordinate and clamps the results.

\section{Hoare Triple}
\subsection*{Precondition}
\subsubsection*{Compiler-verified}
\texttt{MakeNoise} is parameterized as follows:
\begin{itemize}
    \item \texttt{DI} is of type \texttt{VectorDomain<AtomDomain<T>>}
    \item \texttt{MI} is of type \texttt{L1Distance<QI>}
    \item \texttt{MO} implements trait \rustdoc{core/trait}{Measure}
\end{itemize}

The following trait bounds are also required:
\begin{itemize}
    \item Generic \texttt{T} implements trait \rustdoc{traits/trait}{Integer}
    \item Generic \texttt{MO} implements trait \rustdoc{core/trait}{Measure}
    \item Type \texttt{usize} implements trait \rustdoc{traits/trait}{ExactIntCast}\texttt{<T>}
    \item Generic \texttt{QI} implements \texttt{Clone} and \texttt{Debug}
    \item Type \texttt{RBig} implements trait \texttt{TryFrom<QI>}
    \item Type \texttt{ZExpFamily<1>} implements trait \rustdoc{measurements/trait}{NoisePrivacyMap}\texttt{<L1Distance<RBig>, MO>}.
        This bound requires that it must be possible to construct a privacy map for the combination of \texttt{ZExpFamily<1>} noise distribution, distance type and privacy measure.
        The privacy bound for \texttt{ZExpFamily<1>} applies as shown below.
\end{itemize}

\subsection*{Postcondition}
\begin{theorem}
    \validMeasurement{(\texttt{self, input\_space, T, MO})}{\texttt{make\_noise}}
\end{theorem}

\begin{proof}[Data-independent errors]
    The bounds, scale, trial count and threshold are checked at construction and depend only on public parameters.
    The accepted width fits both \texttt{usize} and \texttt{T}.
    The sampled magnitude cannot exceed this width, so its conversion to \texttt{T} succeeds.
    The remaining fallible operations sample independent random bits.
    Inputs at finite $L_1$ distance have the same length, so these operations cannot distinguish such inputs through errors.
\end{proof}

\begin{proof}[Privacy guarantee]
    Input clamping is 1-stable in $L_1$ distance.
    If the bounds coincide, the output is independent of the input values.
    At zero scale the sampler returns the clamped input, as allowed by the privacy map.
    Otherwise, let $s>0$ be the requested scale and $W=U-L>0$ the interval width.

    The continuation probability $q$ is obtained by directed rounding of the reciprocal and exponential, followed by upward grid rounding.
    Thus $e^{-1/s}\leq q<1$ on successful construction.
    Sample a fair sign and a Bernoulli trial with success probability $q$, repeating only if the sign is negative and the trial fails.
    Then draw the remaining $W-1$ trials and use the number of consecutive successes as the censored magnitude.
    The acceptance probability is $(1+q)/2$.
    Dividing the proposal masses by this probability gives $(1-q)q^{|z|}/(1+q)$ for $|z|<W$ and $q^W/(1+q)$ at each of $\pm W$.
    Thus the accepted noise is discrete Laplace with effective scale $s'=-1/\ln q$, censored at $W$.

    Let $x$ be the clamped input and $m$ the sampled magnitude.
    The output is $x+\min(m,U-x)$ or $x-\min(m,x-L)$ according to the sampled sign.
    This is equivalent to adding the signed magnitude and clamping the output.
    Both distances to the bounds are nonnegative and at most $W$, which fits the integer type, and the final result lies in $[L,U]$.
    Thus none of this arithmetic can overflow.
    Censoring does not change this final distribution, since any magnitude at least $W$ already reaches an endpoint.
    Consequently the mechanism is equivalent to 1-stable input clamping, independent discrete Laplace noise, and output clamping.
    Since $s'\geq s$, the privacy bound at the requested scale is conservative:
    $\din/s'\leq\din/s$.
    The privacy guarantee from \rustdoc{measurements/trait}{NoisePrivacyMap}\texttt{<L1Distance<RBig>, MO>} therefore applies.
\end{proof}
