\begin{proof}
    Every binary64 probability $p\in[1/2,1]$ is an exact multiple of $2^{-64}$,
    so the threshold conversion and Bernoulli sampler preserve $p$ exactly.
    The output equals the input with probability $p$ and differs with probability $1-p$.
    For distinct inputs and $p<1$, the maximum pointwise likelihood ratio is $p/(1-p)$.
    Summing over any event preserves this bound.
    The privacy map rounds $\ln(p/(1-p))$ upward using directed arithmetic,
    and returns infinity when $p=1$.
    Equal inputs have identical output distributions and zero privacy loss.
    Entropy failures are independent of the input.
\end{proof}
