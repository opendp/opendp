\section{Hoare Triple}
\subsection*{Precondition}
The input domain is \texttt{AtomDomain<f64>} without NaN, the metric is
\texttt{AbsoluteDistance<f64>}, and sensitivity \texttt{d\_in} is finite and
nonnegative. Invalid parameters are rejected. Compilation evaluates the
specification at an ordered finite epsilon grid, including an accessible
approximate-DP certificate endpoint. Sampled epsilon values must be finite and
nonnegative and deltas must lie in $[0,1]$.
No additional caller assertion of symmetry, convexity, or monotonicity of the
sampled numerical bounds is required.

\section{Certified compilation}
Let $(\epsilon_i,\delta_i)$ be the exact sampled floating-point values,
interpreted as real numbers. Directed interval exponentiation followed by a
lower-directed narrowing supplies a rational $q_i$ with
$1\leq q_i\leq \exp(\epsilon_i)$. Unsupported numerical ranges and provider
errors are rejected, not replaced by weaker bounds. Define $a_i=1-\delta_i$
using exact rational arithmetic and
\[
 f_i(\alpha)=\max\left(0,\ a_i-q_i\alpha,\
                         \frac{a_i-\alpha}{q_i}\right).
\]
Both slopes use the same rational $q_i$, with its exact reciprocal.
Thus $f_i$ is the symmetric approximate-DP tradeoff for parameters
$(\log(q_i),\delta_i)$: its epigraph in the unit square is described by
\[
 \beta\geq0,\qquad \beta+q_i\alpha\geq a_i,\qquad
 \alpha+q_i\beta\geq a_i.
\]
These inequalities are invariant under exchanging $\alpha$ and $\beta$.
Each $f_i$ is convex, nonincreasing and lies below $1-\alpha$.

The compiled envelope $f=\max_i f_i$ is convex and nonincreasing. Its epigraph
is the intersection of the symmetric epigraphs above, so it is exactly
symmetric in the generalized-inverse sense, including any zero plateau.
All evaluations use rational arithmetic, not independently rounded numerical
approximations to the two branches.

The fixed point of $f_i$ is $c_i=a_i/(1+q_i)$. Put $c=\max_i c_i$.
Since every $f_i$ is nonincreasing, $f_i(c)\leq c$, and a component attaining
this maximum has $f_i(c)=c$. Therefore $f(c)=c$ exactly.
Compilation rejects $c=0$ (trivial distinguishability) and $c\geq1/2$
(perfect privacy), so the compiled curve satisfies the nontrivial canonical
noise theorem's preconditions.

\section{Sampling and privacy}
By \cite[Theorem~3.9]{awan2023canonical}, the canonical distribution for the
symmetric nontrivial tradeoff $f$ supplies $f$-DP noise at unit sensitivity.
The PSRN inverse-CDF algorithm evaluates this exact rational envelope and
its exact fixed point, scales by \texttt{d\_in} and shifts by the input.
The finite clamping of infinite input endpoints is nonexpansive. Final
rounding to a float is postprocessing. Construction-time specification
errors do not occur during sampling; random-generator failures propagate
and are data-independent.

Since $f\geq f_i$, this mechanism satisfies
$(\log(q_i),\delta_i)$-DP and hence $(\epsilon_i,\delta_i)$-DP at every
sampled point. Let $h(\epsilon)$ be its actual privacy profile. This profile
is nonincreasing, regardless of whether the numerical samples were monotone.
For every $\epsilon\geq0$,
\[
 h(\epsilon)\leq
 \min_{i:\epsilon_i\leq\epsilon}h(\epsilon_i)
 \leq \min_{i:\epsilon_i\leq\epsilon}\delta_i
 = S(\epsilon).
\]
An empty minimum is defined to be one; beyond the final point the last prefix
minimum is retained. Thus the step envelope is a globally valid certificate,
not merely an interpolation assumed valid between calibration points.

The log-native profile stores the final minimum as exact additive slack and
uses directed logarithms for the nonnegative remainder. Its reported bounds
therefore enclose $S$ conservatively; when the core is zero, the final minimum
is returned exactly. This is an encoding of the step envelope, not a transfer
of source delta from an unrelated input representation.

For positive distances no greater than \texttt{d\_in}, the privacy map returns
a fresh guarantee with only this profile. Zero distance returns a perfect
privacy log profile; it does not evaluate a rounded expression $1-\alpha$.
The descriptor advertises a profile, and advertises purity only when a zero
delta was sampled at a finite epsilon or the only admissible distance is zero.
No input RDP, zCDP or Gaussian-DP representation is copied to the output.
Consequently each successful privacy-map result certifies the sampled
mechanism for all admissible distances.
