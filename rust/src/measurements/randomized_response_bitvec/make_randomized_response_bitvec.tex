\section{Introduction}
This is a randomizer in the local model of differential privacy, which is a simplification of the RAPPOR protocol~\cite{rappor}. Under local differential privacy each user is guaranteed $\varepsilon$-DP for their response. RAPPOR achieves local differentially private frequency estimation by flipping each bit of an input vector with fixed probability. Because the noise is added mechanically we can efficiently post-process a set of outputs from this randomizer with the function \rustdoc{measurements/fn}{debias\_randomized\_response\_bitvec}, which sums and normalises a vector of private outputs using the quantized flip probability to account for the bias introduced. The input to this function are elements from a \rustdoc{domains/struct}{BitVectorDomain} with fixed $\texttt{max\_weight}$ and $\texttt{size}$. The former bounds sensitivity; the latter ensures that output length does not reveal the input. we detail two use cases below to explain two possible settings of $\texttt{max\_weight}$, which we will denote $m$.

Frequency estimation is the problem of generating a histogram of the empirical frequencies of categorical elements. Any categorical domain of size $k$ can be mapped to the set $[k]=\{0,1,\ldots,k-1\}$, and we can represent any element $j\in[k]$ as the $j$'th standard basis vector so that $m=1$. In cases where the domain is extremely large or even unbounded (such as a set of strings) we can hash the domain elements using a bloom filter with $m$ hash functions. In order to decode a set of outputs generated in this fashion we must perform a regression against the bloom filter representations of a set of candidate elements, neither bloom filters nor the regression tools required for this are implemented here, but details can be found in the original RAPPOR paper. For utility, $m$ should be much less than $k$. As we will prove in~\ref{thm:privacy-parameter} privacy degrades linearly with $m$.

\subsection{Privacy}

\begin{tcolorbox}
\begin{note}[Fixed-width Bernoulli sampler]
Set $q=\texttt{threshold}/2^{64}$, where \texttt{threshold} is the
upward-rounded grid threshold for $f/2$, with a minimum of one. The sampler returns true
with probability exactly $q$, and $f/2\le q\le 1/2$.
The probability $q$ is exactly representable as binary64: scaling a binary64 by $2^{64}$ is exact, and rounding up to an integer preserves representability.
The minimum threshold of one also preserves representability.
An entropy failure is independent of the input data.
\end{note}
\end{tcolorbox}
\begin{theorem}[\cite{rappor}]
\label{thm:privacy-parameter}
	The program \rustdoc{measurements/fn}{make\_randomized\_response\_bitvec} satisfies $\varepsilon$-DP, where
	\begin{equation*}
		\varepsilon = 2m\log\left(\frac{1-q}{q}\right).
	\end{equation*}
\end{theorem}
\begin{proof}
    Any two members $x,x'$ of the input domain have the same length $k$ and at most $m$ ones each.
    Thus they differ in at most $2m$ coordinates.
    For each coordinate, the output equals the input with probability $1-q$ and differs with probability $q$.
    Since $0<q\leq 1/2$, the likelihood ratio at a differing coordinate is at most $(1-q)/q$;
    at an agreeing coordinate it is one.
    By independence, for every report $y\in\{0,1\}^k$,
    \[
        \frac{\Pr[Y=y\mid X=x]}{\Pr[Y=y\mid X=x']}
        \leq \left(\frac{1-q}{q}\right)^{2m}.
    \]
    Summing the pointwise inequality over any event gives the same bound.
    The implementation rounds the privacy parameter upward using directed arithmetic.
    At distance zero, the inputs are identical and the privacy loss is zero.
\end{proof}

\subsection{Utility}

\begin{theorem}
    In exact arithmetic, for $q<1/2$, the debiasing estimator is unbiased and has mean squared error
    \[
        \mathbb{E}[\|\hat h-h\|_2^2]=\frac{nkq(1-q)}{(1-2q)^2}.
    \]
\end{theorem}
\begin{proof}
    Fix $n$ input vectors of length $k$ and let $h_j$ and $Y_j$ denote the true and randomized counts at coordinate $j$.
    Each of the $h_j$ ones is reported as one with probability $1-q$, and each of the remaining bits with probability $q$.
    By independence,
    \[
        \mathbb{E}[Y_j]=nq+(1-2q)h_j,\qquad
        \operatorname{Var}(Y_j)=nq(1-q).
    \]
    Thus $\hat h_j=(Y_j-nq)/(1-2q)$ has expectation $h_j$ and variance $nq(1-q)/(1-2q)^2$.
    Summing these variances over the $k$ coordinates gives the stated mean squared error.
\end{proof}
